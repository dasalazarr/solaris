# El equipo también tiene contrato

*Borrador. Pendiente de revisión.*

Queríamos un equipo de agentes. Uno para la landing, otro para el producto, más adelante comunicación y diseño. La primera idea fue montarlo sobre una plataforma de agentes ya hecha.

La descartamos. Ejecutaba los agentes sin pedir confirmación por acción y guardaba su memoria fuera del repositorio. Justo lo contrario de lo que vendemos.

## Qué decidimos

Aplicar Solaris a nosotros mismos. Cada agente es un proceso con contrato: un responsable humano, un KPI, unas reglas y una lista de lo que puede hacer sin preguntar.

Los agentes no son dueños de nada. Proponen y miden. El dueño sigue siendo una persona.

## Las reglas son código

Escribimos como código las reglas que nos frenan:

- No se propone un test A/B sin tráfico medido. Hoy no tenemos tráfico, así que no hay A/B.
- No se acepta un insight de mercado sin fuente.
- Ninguna entrada de este diario sale sin estar marcada como publicada.

Si alguien las incumple, el lint falla. No depende de que el modelo se acuerde.

## Qué aprendimos

La tentación de construir la organización antes que el producto es real. La frenamos con el mismo método que proponemos a nuestros clientes: contrato, evidencia, regla y revisión.
