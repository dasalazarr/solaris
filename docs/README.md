# docs

Fuente de verdad compartida entre `product/` y `landing/`.

| Fichero              | Estado                                                                 |
|----------------------|------------------------------------------------------------------------|
| `prd-producto.md`    | **Pendiente.** Diego lo exporta cuando tenga acceso.                   |
| `prd-landing.md`     | **Pendiente.** Igual que el anterior.                                  |
| `marca.md`           | Vigente. Identidad visual común.                                       |
| `decisiones/`        | Una nota por decisión con consecuencias (contexto, opciones, decisión, consecuencias). |
| `diario/`            | Borradores para construcción en público. Diego revisa y publica.       |

Mientras no existan los PRD, la única referencia de alcance es el plan de implementación generado en AI Studio (`product/.aistudio/artifacts/brain/…/implementation_plan.md`). Es provisional: **no** se toman decisiones de alcance nuevas con él.
